## Other findings that changed the build

- **Missing required peers.** `agents@0.27.0` has non-optional peers on `@modelcontextprotocol/client`, `/sdk` and `/server` and imports them at load time; `agents/vite` needs `@babel/core`. PLAN §12 lists none of them. They are pinned explicitly in `apps/api` (and the MCP trio in `apps/web`).
- **npm 10.9 resolver crash.** `npm install` fails with `Cannot read properties of null (reading 'edgesOut')` on this dependency tree whichever package is removed. The repo ships `.npmrc` with `legacy-peer-deps=true`, so peers are not auto-installed and must be declared (see above). `npm ci` works with the lockfile.
- **Identity leak closed.** By default an agent sends its instance name (here the internal user id) to every client in a `cf_agent_identity` frame. Both agents set `static options = { sendIdentityOnConnect: false }`; `routing.test.ts` asserts that no frame on either socket contains the user id. The client does not need identity (`useAgentChat` does not wait for `agent.ready`).
- **Suspense placement.** `useAgentChat` suspends while it fetches history. A `Suspense` boundary above `useAgent` hides that tree and React then runs the connection hook's effect cleanup, which threw `destroy is not a function` and blanked the screen. The boundary now wraps only `<Chat>`.
- **`withVoiceInput` has no `forceEndCall`.** The 60-second cap closes the socket (`connection.close`) and the client stops the mic at the same limit.
- **Voice exports live in `agents`.** `withVoiceInput`, `WorkersAINova3STT` and `useVoiceInput` are exported from `agents/voice` and `agents/voice/react`, so `@cloudflare/voice` is not installed.
- **AI SDK 7 names.** `isStepCount` is the current name (`stepCountIs` is an alias); `repairToolCall` is no longer experimental; token usage is `{ inputTokens, outputTokens }`.
